# Ηλεκτρονικός Πτωχοπρόδρομος

Διαδραστική online έκδοση των ποιημάτων του Πτωχοπροδρόμου, βασισμένη στις
TEI-XML μεταγραφές των χειρογράφων (`data/xml/`).

- **Ποίημα Α΄** — ένα χειρόγραφο (G), με διορθώσεις εκδοτών σημειωμένες με `<choice>`.
- **Ποίημα Β΄** — παράλληλη μεταγραφή δύο χειρογράφων (G, H) μέσω `<app>/<rdg>`.
- **Ποίημα Γ΄** — επτά χειρόγραφα (S, A, C, G, M, P, K) και το κείμενο της έκδοσης
  Eideneier (`<lem>`), με πλήρες κριτικό υπόμνημα.
- **Ποίημα Δ΄** — ένα κείμενο της έκδοσης Eideneier (665 στίχοι) με το κριτικό υπόμνημα ως †
  σε κάθε στίχο, και 86 στίχους που σώζονται μόνο σε ορισμένα χειρόγραφα (στίχοι N-M, με σίγλα).
  Το XML ανακατασκευάστηκε από το HTML της Cambridge (άδεια CC BY-NC-ND 3.0).
- **Ποίημα Majuri** («στίχοι δεητήριοι») — έκδοση A. Majuri, BZ 23 (1920) 397–407, από το
  χφ. V (Vaticanus graecus 1823). Οι αποκλίσεις του χειρογράφου εμφανίζονται ως † και τα
  φύλλα (fol. 195v, 196r) ως διαχωριστικά. Άδεια: CC BY-NC-SA 3.0.

## Πώς λειτουργεί

Το `scripts/build-data.mjs` διαβάζει τα αρχεία TEI-XML και τα μετατρέπει σε ένα
γενικό, σειρά-διατηρητικό JSON δέντρο (`src/data/poems.json`, δεν παρακολουθείται
στο git — παράγεται σε κάθε build). Το frontend (`src/tei.ts`) διαθέτει έναν
**γενικό** renderer που ερμηνεύει οποιοδήποτε `<app>`, `<choice>`, `<supplied>`,
`<note>` κ.λπ. για το επιλεγμένο χειρόγραφο, χωρίς ειδική λογική ανά ποίημα — έτσι
το ίδιο view κάνει render και το απλό ποίημα Α΄ και το πολυ-μαρτυρικό ποίημα Γ΄.

Λειτουργίες:

- Επιλογή χειρογράφου/έκδοσης ανά ποίημα.
- Εναλλαγή προβολής «γραφή χειρογράφου» (`sic`) / «διόρθωση» (`corr`).
- Στίχοι που λείπουν από ένα χειρόγραφο (`void`) εμφανίζονται με `—`.
- Κριτικές σημειώσεις (`<note>`) και συμπληρώσεις (`<supplied>`) με tooltip.
- Αναζήτηση κειμένου σε όλα τα ποιήματα.

## Ανάπτυξη

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # παράγει dist/
```

`npm run data` ξαναδημιουργεί το `src/data/poems.json` από τα XML αρχεία (τρέχει
αυτόματα πριν από `dev`/`build`).
